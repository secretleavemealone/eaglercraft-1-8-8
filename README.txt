Release 1.8.8 JavaScript package

Files:
- index.html: page structure, styles, and the embedded Eaglercraft client data.
- client.js: the JavaScript that was originally embedded in the HTML.

Run:
Open index.html in a browser, or serve this folder with a local web server.

Note:
This separates the original inline JavaScript into client.js. The Eaglercraft client
payload itself remains embedded in index.html in its original compressed data format;
it is not Java source code and has not been rewritten from scratch.
